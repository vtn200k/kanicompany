KANI ENTERTAINMENT — WEBSITE ĐA TRANG
=========================================
Các trang:
- index.html: Trang chủ
- gioi-thieu.html: Giới thiệu
- dich-vu.html: Dịch vụ
- quy-trinh.html: Quy trình
- talent.html: KANI Talent
- du-an.html: Dự án
- tin-tuc.html: Tin tức
- lien-he.html: Liên hệ
- style.css: Giao diện dùng chung
- script.js: Hiệu ứng và menu

Cách dùng:
1. Giữ nguyên tất cả file trong cùng một thư mục.
2. Mở index.html bằng Chrome/Safari.
3. Các menu sẽ liên kết sang từng trang riêng.
